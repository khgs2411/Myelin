# Prioritize the V2 brain over V1 compatibility

V1 LLM Wiki provides limited operator value and is not used enough to justify preserving weak behavior at the cost of the V2 design. The TypeScript migration may break existing commands, layouts, artifacts, and pipeline semantics when doing so creates a better foundation for the powerful memory product. The migration should still preserve useful project knowledge, raw sources, and provenance unless they are intentionally rejected. Compatibility is a tool for protecting valuable data and operator intent, not a default constraint.
