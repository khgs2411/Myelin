# Allow project learn to read the live repo directly

`project learn <key>` may inspect the live repository directly instead of requiring every learnable source to pass through an explicit intake layer first. This keeps Project Memory practical and avoids turning the inbox into a bottleneck for ordinary repo-grounded learning. Durable Project Memory writes produced from live repo reads must preserve traceable evidence and provenance, such as file paths, commit or state pointers, source snippets, artifact ids, or explicit inference labels.
