# Keep curated Project Memory in markdown plus metadata JSON

Curated Project Memory remains human-readable markdown pages plus metadata JSON during V2. SQLite should not become the source of curated truth in the TypeScript migration or the first memory slice. SQLite belongs to serving, recall, session continuity, event capture, queues, and vector metadata until a future design explicitly changes that boundary. This keeps the trusted brain inspectable while still allowing faster structured retrieval layers.
