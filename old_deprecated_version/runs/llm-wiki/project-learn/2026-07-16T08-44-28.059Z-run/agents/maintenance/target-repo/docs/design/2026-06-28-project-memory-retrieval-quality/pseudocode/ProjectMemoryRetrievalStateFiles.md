# ProjectMemoryRetrievalStateFiles

Pseudocode artifact. Non-executable reference shape for planning.

## Intended Destination

Project-local generated state under:

```text
projects/<key>/state/project-memory-retrieval/
  sections.json
  hints/
    <category>.json
  hint-status.json
```

## Ownership

`wiki/` owns human-readable canonical Project Memory.

`state/project-memory-retrieval/sections.json` owns deterministic structural retrieval metadata derived from `wiki/`.

`state/project-memory-retrieval/hints/*.json` owns semantic hint metadata generated by a separate hint-generation model.

`state/project-memory-retrieval/hint-status.json` owns validation status, staleness, and refresh diagnostics for hint entries.

## Non-Ownership

- State files do not become canonical memory.
- Hint files do not authorize markdown writes.
- Hint files do not define which markdown sections exist.
- SQLite vector rows do not override these state files or markdown.

## `hint-status.json` Shape

```json
{
  "schema_version": 1,
  "project_key": "llm-wiki",
  "validated_at": "2026-06-28T00:00:00.000Z",
  "entries": [
    {
      "wiki_path": "wiki/architecture/ranking-and-proposal-generation.md",
      "section_id": "ranking-and-proposal-generation",
      "status": "valid",
      "reason": null
    }
  ],
  "counts": {
    "valid": 1,
    "stale": 0,
    "orphaned": 0,
    "missing_required": 0
  }
}
```

## Status Vocabulary

- `valid`: hint section hash matches current structural metadata.
- `stale`: hint points to an existing section but section hash changed.
- `orphaned`: hint points to a missing wiki path or missing section id.
- `missing_required`: new page/entry has no hint entry.
- `needs_reembed`: hint is valid but embedding contract changed.
- `low_confidence`: usage feedback says retrieval quality was poor.

## Failure Posture

Invalid hint JSON must not block reading canonical markdown. It should:

- mark hint validation degraded;
- exclude invalid hints from embedding text;
- preserve the invalid file for inspection;
- enqueue retrieval maintenance when appropriate.
