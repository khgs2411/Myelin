# Treat project-management tools as source evidence, not product primitives

LLM Wiki does not model Trello cards, Jira issues, Linear issues, ClickUp tasks, or any other project-management tool as core product concepts. Those tools may appear in Project Memory, Session Memory, or the Experience Log as external source evidence, but product contracts use neutral language such as external work-tracker context. This keeps the memory model portable when the operator changes project-management tools while still allowing LLM Wiki to document tool usage as part of project or personal memory.
