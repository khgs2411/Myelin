# Support

This project is maintained as open source.

## Where To Ask

- Use GitHub issues for bugs, reproducible problems, and focused feature requests.
- Use pull requests for proposed documentation or code changes.

## What To Include

- what you were trying to do
- exact command or workflow
- expected result
- actual result
- relevant logs or error output

## Boundaries

Maintainers may close issues that are incomplete, unrelated to the project, duplicates, or outside the current scope.
