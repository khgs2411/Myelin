# Gate risky project learn changes

Routine additive or corrective `project learn` updates with good provenance should auto-apply. `project learn` must switch to review or dry-run for destructive deletes, superseding a decision record, low-confidence synthesis, conflicting sources, broad rewrites across multiple memory areas, or explicit `--review` / `--dry-run`. This preserves day-to-day usefulness while preventing the self-learning path from silently corrupting important memory.
