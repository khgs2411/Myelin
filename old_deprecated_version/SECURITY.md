# Security Policy

## Reporting A Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report security concerns privately to the maintainer through the repository owner's GitHub profile contact options. Include:

- affected version or commit
- reproduction steps
- expected impact
- any relevant logs or proof of concept

## Supported Versions

This project is early-stage. Security fixes target the current `master` branch unless a maintained release line is announced later.

## Disclosure

Please give the maintainer a reasonable opportunity to investigate and release a fix before public disclosure.
