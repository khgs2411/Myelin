# Structured Recall

## Outcome

Myelin can answer state and continuity questions from structured SQLite data.

## Why it matters

Not every recall problem needs embeddings or model synthesis.

## Scope

- Sessions.
- Events.
- Candidate queues.
- Freshness and run state.

## Done means

- Common status questions are answered without model calls.
- Degraded state is explicit when structured data is missing.
