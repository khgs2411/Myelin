# Provider Profiles

## Outcome

Myelin can choose provider/model profiles by workload.

## Why it matters

Pipeline, query, and promotion work may need different models and reasoning levels.

## Scope

- Default provider.
- Per-workload profile.
- Model override.
- Reasoning-effort configuration where supported.

## Done means

- Config and env overrides are clear.
- Unsupported providers fail explicitly.

## Notes

- Related: ADR 0051.
