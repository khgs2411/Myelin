# Project Memory Update Candidate

## Outcome

Myelin can represent a proposed update to curated Project Memory before applying it.

## Why it matters

Durable wiki changes need provenance, confidence, and review gates before they become trusted memory.

## Scope

- Target page or page area.
- Source evidence.
- Proposed fact or correction.
- Confidence and risk classification.
- Apply/review decision state.

## Done means

- Candidates can be listed and inspected.
- Risky or ambiguous changes do not silently apply.
