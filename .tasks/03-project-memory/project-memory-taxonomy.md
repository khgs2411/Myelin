# Project Memory Taxonomy

## Outcome

Myelin has a clear taxonomy for the kinds of durable project knowledge that belong in curated wiki pages.

## Why it matters

Without a taxonomy, Project Memory can drift into generic repo docs, code summaries, or scattered notes.

## Scope

- Product behavior.
- Feature intent.
- Architecture decisions.
- Operating runbooks.
- Setup gotchas.
- Manual QA flows.
- Current state.
- Provenance and source history.

## Done means

- Agents can decide whether a fact belongs in Project Memory or should remain source evidence.
- The taxonomy discourages mirroring repo structure.
- Wiki pages can be validated against the taxonomy.
