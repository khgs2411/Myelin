# Curated Page Update

## Outcome

Routine, well-sourced Project Memory updates can modify existing canonical wiki pages.

## Why it matters

The wiki should compound understanding without creating duplicate or speculative pages.

## Scope

- Prefer updating existing canonical pages.
- Preserve provenance.
- Mark inference and uncertainty.
- Keep source material separate from synthesis.

## Done means

- A small sourced change can be applied and validated.
- Page metadata or provenance records reflect the update.

## Notes

- Related: AGENTS.md wiki writing rules and ADR 0021.
