# Personal Preference Candidate

## Outcome

Myelin can queue a possible durable user preference from repeated corrections or explicit guidance.

## Why it matters

User preferences should become durable only when they are real, scoped, and useful.

## Scope

- Preference statement.
- Evidence source.
- Applicability boundaries.
- Confidence and review state.

## Done means

- One-off corrections do not automatically become broad preferences.
- Candidates can be reviewed before promotion.
