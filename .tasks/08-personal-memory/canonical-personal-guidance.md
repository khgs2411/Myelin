# Canonical Personal Guidance

## Outcome

Accepted personal preferences live as canonical guidance that agents can retrieve.

## Why it matters

Agents should adapt to Liad's way of working without relying on fragile conversation history.

## Scope

- Working style.
- Testing preferences.
- Planning/review habits.
- Tooling preferences.
- Scope and exceptions.

## Done means

- `how` and `query` can cite personal guidance when relevant.
- Guidance is scoped enough to avoid over-applying it.

## Notes

- Personal Memory should be promoted with judgment, not inferred casually.
