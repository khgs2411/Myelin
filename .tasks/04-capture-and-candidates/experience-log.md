# Experience Log

## Outcome

Myelin has a raw event log that captures evidence without treating it as truth.

## Why it matters

Session, Project, Practice, and Personal Memory should be derived from observed work, but raw events must not become canonical memory by accident.

## Scope

- Raw activity events.
- Project and session association.
- Source/tool metadata.
- Event timestamps.
- Retention and compaction boundaries.

## Done means

- Raw events can be queried as evidence.
- Curated memory writes still require promotion or explicit repair.
- High-volume capture does not pollute human-readable wiki pages.
