# Gap Curator

## Outcome

Low-confidence, stale, or corrected answers can become concrete repair work.

## Why it matters

The product needs a feedback loop from "the memory failed me" to "there is a traceable item to repair memory."

## Scope

- Low-confidence query result.
- Stale-answer flag.
- User correction.
- Failed route or missing page.
- Inbox item or memory candidate output.

## Done means

- A weak answer can create a bounded repair item.
- The repair item cites the question, pages read, confidence, and correction evidence when available.
- The repair path does not silently mutate curated Project Memory.
