# Memory Candidate Queue

## Outcome

Myelin can queue memory candidates targeted at exactly one scope.

## Why it matters

The system needs a holding area between raw experience and trusted memory.

## Scope

- Project Memory candidate.
- Session Memory candidate.
- Practice Memory candidate.
- Personal Memory candidate.
- Candidate status lifecycle.

## Done means

- Candidates can be created, listed, and marked processed or needs-review.
- Candidate routing is deterministic.

## Notes

- Related: ADR 0006.
