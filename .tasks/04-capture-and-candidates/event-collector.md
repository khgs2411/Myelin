# Event Collector

## Outcome

Myelin can append structured raw events for project work.

## Why it matters

Project, session, practice, and personal memory should derive from real work, not detached notes.

## Scope

- Detect project context.
- Write raw events.
- Avoid model calls.
- Avoid curated memory writes.

## Done means

- Hook or CLI-originated events land in durable serving state.
- Event writes are cheap and deterministic.

- Related: `MYELIN.md` section 9.3 and ADR 0003.
