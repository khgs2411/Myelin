# Project Onboard

## Outcome

`myelin project onboard <key>` creates the minimum project memory structure for a repo.

## Why it matters

New projects need a clear starting path instead of manual folder setup.

## Scope

- Project directory layout.
- Initial schema context.
- Initial wiki/index placeholders.
- Status output that explains what is missing.

## Done means

- A new project can be registered and pass basic schema/status checks.
- No speculative project knowledge is invented.
