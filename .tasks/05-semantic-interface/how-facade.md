# How Facade

## Outcome

Agents can ask for prescriptive operating guidance through a `how` facade.

## Why it matters

Operating guidance should prefer canonical Practice/Personal guidance and project-specific overrides, not random project examples.

## Scope

- Project runbooks.
- Practice Memory.
- Personal workflow preferences.
- Current project exceptions.

## Done means

- `how` distinguishes guidance from explanation.
- Project examples are labeled as provenance, not copied as authority.
