# Project Ingest Flow

## Outcome

Queued source material and inbox items can be processed into preserved sources, candidates, or curated memory updates.

## Why it matters

Ingest is the narrow source-processing path. It should not be collapsed into broad repo learning.

## Scope

- Inbox item selection.
- Source preservation.
- Classification.
- Apply or candidate creation.
- Validation.
- Terminal source status.

## Done means

- An inbox item can move from pending input to a terminal status.
- Source material is preserved before synthesis.
- Failed validation leaves reviewable state.
