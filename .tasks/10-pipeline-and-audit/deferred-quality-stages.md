# Deferred Quality Stages

## Outcome

The pipeline can support acceptance, reconcile, self-correct, and measure stages when the core path is ready.

## Why it matters

Quality loops matter, but adding them before the basic memory artifact works would create premature machinery.

## Scope

- Acceptance questions.
- Bounded reconcile.
- Self-correction.
- Measurement.

## Done means

- Each stage has a clear contract before implementation.
- Validate failures stay explicit.

## Notes

- Related: ADR 0053.
