# Project Memory Curator

## Outcome

A bounded curator can decide whether project evidence should update durable Project Memory.

## Why it matters

The evolved `project learn` path should ask what durable knowledge changed, not merely run stages.

## Scope

- Meaningful session output.
- Commit or repo evidence.
- Existing wiki pages.
- Candidate creation or routine update.
- Review gates.

## Done means

- The curator distinguishes behavior/runbook/decision changes from code an agent can read directly.
- Updates are focused, sourced, and validated.
- Broad or low-confidence changes require review.
