# Review Gates

## Outcome

Risky learning changes automatically switch to review or dry-run behavior.

## Why it matters

The system should improve memory without silently corrupting it.

## Scope

- Destructive deletes.
- Decision-record supersession.
- Low-confidence synthesis.
- Conflicting sources.
- Broad multi-area rewrites.

## Done means

- Routine sourced updates can auto-apply.
- Risky changes require review.

## Notes

- Related: ADR 0020.
