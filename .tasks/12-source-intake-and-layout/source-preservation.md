# Source Preservation

## Outcome

Original source material is preserved separately from synthesized wiki content.

## Why it matters

Provenance is only useful if the source survives and can be audited later.

## Scope

- `raw/` intake.
- `projects/<key>/sources/`.
- Source metadata.
- Source status.
- Links from wiki updates back to preserved material.

## Done means

- Ingest never rewrites or deletes preserved sources.
- Wiki claims can cite preserved evidence.
- Terminal source status is visible.
