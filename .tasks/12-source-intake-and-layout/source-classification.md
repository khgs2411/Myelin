# Source Classification

## Outcome

New source material is classified before it affects memory.

## Why it matters

The product should preserve evidence and choose the right action instead of treating every input as a wiki update.

## Scope

- Source kind.
- Ownership.
- Destination.
- Update targets.
- Action.

## Done means

- Every consumed source has a classification record.
- Ambiguous ownership can be marked needs-review.
- Rejected sources have an explicit reason.

## Notes

- Allowed actions should match the project contract: update existing pages, create new page and update index, log-only, reject, or needs-review.
