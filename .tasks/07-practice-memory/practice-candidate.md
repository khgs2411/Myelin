# Practice Candidate

## Outcome

Myelin can represent a possible cross-project practice derived from project evidence.

## Why it matters

Repeated workflows should become reusable guidance without copying one project as authority.

## Scope

- Candidate title.
- Source projects.
- Evidence snippets or citations.
- Proposed canonical guidance.
- Confidence and review state.

## Done means

- Practice candidates can be queued without auto-promoting.
- Source projects are provenance, not instructions.

## Notes

- Promotion should stay manual until the shape is proven.
