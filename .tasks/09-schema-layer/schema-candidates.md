# Schema Candidates

## Outcome

Myelin can queue, list, and apply proposed schema changes.

## Why it matters

Schema affects future agent behavior, so changes need a higher bar than routine memory edits.

## Scope

- Candidate storage.
- Candidate states.
- Project-local and global ownership.
- Apply flow.

## Done means

- `schema candidates` and `schema apply` exist for the supported scope.
- Global changes require explicit intent.

## Notes

- Related: ADRs 0031, 0032, and 0040-0046.
