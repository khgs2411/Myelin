# Project-Local Schema

## Outcome

Projects can define local schema conventions that specialize global rules.

## Why it matters

Different repositories may need different page conventions, vocabulary, or maintenance rules.

## Scope

- Project-local authored schema files.
- Merge with global schema.
- Generated schema context.

## Done means

- Project-local schema can extend or narrow global rules.
- Generated context records input hashes.

## Notes

- Deferred beyond Phase 0 by ADR 0049.
