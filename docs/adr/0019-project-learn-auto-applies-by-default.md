# Auto-apply routine project learning by default

`project learn <key>` should apply routine curated Project Memory updates by default. Requiring operator review for every learning run would make the product too expensive to use day to day and would undermine the purpose of a self-improving brain. Review/proposal and dry-run modes should still exist for risky changes, debugging, or manual control, but they are opt-out controls rather than the daily default. Applied changes must leave reviewable artifacts, provenance, and a rollback or review trail.
