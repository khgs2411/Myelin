# LLM Wiki Design

Continue design in the [current consolidated unit](2026-09-03-shared-captured-activity-seam/README.md).

That unit owns the current Feature Shape, Open Design Issues, and detailed
pseudocode. The root [README](../../README.md) owns the product overview;
[ROADMAP](../../ROADMAP.md) owns delivery order and completion status.

All other dated units are historical source records. Their design bodies and
milestone references remain available. Their issue lists and older pseudocode
do not create a second active design frontier. The current unit records which
questions and boundaries survive consolidation.
